## 🚀 使用方式

### 方法一：網頁匯入 (推薦)

1. 啟動系統 (本地版或線上版)
2. 登入系統
3. 點選左側選單的 **「匯入資料 (Import)」**
4. 選擇 `sample_data.json` 檔案
5. 確認匯入
6. 系統將自動載入範例資料

### 方法二：直接複製 (本地版)

1. 確保系統未運行
2. 複製 `sample_data.json` 到 `data/` 資料夾
3. 重新命名為 `Spe for u.json` (預設使用者 ID)
4. 啟動系統並登入

## ✨ 體驗建議流程

匯入範例資料後，建議依序體驗以下功能：

### 1. 學生管理 👨‍🎓
- 查看學生列表 (7-9 年級)
- 嘗試點擊年級數字快速切換
- 新增一位測試學生

### 2. 課程管理 📚
- 查看 5 門課程的設定
- 編輯課程資訊 (如調整節數)
- 查看各組的教師與教室分配

### 3. 分組管理 👥
- 選擇「國文」課程
- 觀察學生分組情況
- 嘗試拖曳學生到不同組別

### 4. 簡易課表 📅
- 查看週課表 (已排課)
- 嘗試移除並重新排入課程
- 觀察課程區塊顯示剩餘節數

### 5. 總課表 📋
- 切換不同檢視模式:
  - 總課表 (完整資訊)
  - 教師課表 (選擇王老師)
  - 學生課表 (選擇張小明)
- 嘗試單節微調功能

### 6. Word 匯出 📘
- 匯出簡易課表
- 匯出教師個別課表
- 匯出學生個別課表
- 檢查格式與內容

### 7. 資料備份 💾
- 匯出目前資料 (JSON)
- 清空所有資料
- 重新匯入備份檔案

## 🔧 自訂範例資料

如需修改範例資料，請編輯 `sample_data.json` 檔案：

```json
{
  "students": [...],      // 修改學生資料
  "courses": [...],       // 修改課程設定
  "teachers": [...],      // 修改教師資料
  "groupAssignments": {...}, // 修改分組
  "schedule": {...},      // 修改排課
  "scheduleTitle": {...}  // 修改課表標題
}
```

**注意事項**:
- 確保 `id` 欄位唯一
- `groupAssignments` 的學生 ID 必須存在於 `students`
- `schedule` 的 `courseId` 必須存在於 `courses`

## 💡 常見問題

**Q: 匯入範例資料會覆蓋我的資料嗎？**  
A: 是的。匯入前請先匯出備份目前的資料。

**Q: 可以部分匯入嗎？**  
A: 目前僅支援完整匯入。如需保留部分資料，請手動編輯 JSON 檔案。

**Q: 範例資料可以用於正式環境嗎？**  
A: 範例資料僅供測試與學習。正式使用請建立實際的學生與課程資料。
